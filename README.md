# EigenVision — PCA-Based Face Recognition

## Overview

EigenVision is a computer vision project that demonstrates face recognition using Principal Component Analysis (PCA), a mathematical technique for dimensionality reduction.

The project captures face images through a webcam, preprocesses them into numerical feature vectors, trains a PCA-based recognition model, and identifies known faces in real time. It also visualizes eigenfaces to illustrate how mathematical components represent variations in facial images.

EigenVision was developed to explore the relationship between linear algebra, statistics, dimensionality reduction, and practical face recognition.

## Project Objectives

- Apply PCA to facial image data.
- Understand eigenvalues, eigenvectors, covariance matrices, and principal components.
- Represent high-dimensional facial images using a smaller set of features.
- Implement webcam-based face detection and recognition.
- Visualize eigenfaces and understand their role in facial representation.
- Demonstrate the practical application of mathematical concepts in computer vision.

## Key Features

### 1. Face Capture

Captures facial images using a webcam and saves them in person-specific folders. The capture process detects faces, converts them to grayscale, and resizes them to a consistent image size.

### 2. Image Preprocessing

Prepares facial images for PCA by applying histogram equalization, resizing, pixel normalization, mean removal, and vector normalization.

### 3. PCA Model Training

Computes the mean face, centers the training data, calculates a sample-space covariance matrix, and extracts eigenvalues and eigenvectors to construct eigenfaces.

### 4. Eigenface Visualization

Displays up to 12 eigenfaces in a grid using Matplotlib. This helps illustrate the principal components learned from the training images.

### 5. Real-Time Face Recognition

Uses a webcam to detect faces and compare their PCA feature representations with the average feature vectors of known individuals.

### 6. Unknown Face Detection

Compares the nearest recognition distance with a configured threshold to classify faces as known or unknown.

### 7. Prediction Stabilization

Uses recent predictions across multiple frames to reduce rapid changes in displayed identity labels.

### Prerequisites

Install Python and ensure your webcam is accessible.


## How to Use

After starting the program, select an option from the interactive menu.

1. **Capture faces:** Enter a person's name and capture facial images using the webcam. Repeat this for each person you want to include.
2. **Train PCA model:** Load the captured images and train the recognition model. At least two different people with usable face images are required.
3. **Show eigenfaces:** Visualize the principal facial components extracted from the training dataset.
4. **Start face recognition:** Open the webcam and identify faces against the trained dataset.
5. **Exit:** Close the application.

Press `Q` in the webcam window to stop face capture or recognition.

For meaningful results, capture images under varied facial angles and lighting conditions.

## How It Works

### Step 1: Image Collection

Facial images are collected from the webcam and stored in separate folders for each individual.

### Step 2: Preprocessing

Each image is converted into a grayscale image of 100 × 100 pixels and transformed into a normalized vector containing 10,000 pixel values.

### Step 3: Mean Face Calculation

The average of all training face vectors is calculated to obtain the mean face.

### Step 4: Data Centering

The mean face is subtracted from each training vector to center the dataset around its mean.

### Step 5: Covariance Matrix

Instead of constructing a 10,000 × 10,000 covariance matrix, the implementation calculates a covariance matrix in sample space. This reduces the matrix size when the number of training images is smaller than the number of pixels.

### Step 6: Eigenvalues and Eigenvectors

The covariance matrix is decomposed to obtain eigenvalues and eigenvectors. The components are sorted by descending eigenvalue, and numerical zero or negative eigenvalues are discarded.

### Step 7: Eigenface Generation

The selected eigenvectors are transformed into eigenfaces, which form a lower-dimensional representation of the training images.

The model retains up to 25 principal components, subject to the number of available valid components and training samples.

### Step 8: Feature Extraction

Each training image is projected into PCA space to obtain a compact feature vector. The average feature vector for each person is calculated to form a class centroid.

### Step 9: Recognition

A newly detected face is preprocessed and projected into the same PCA space. Its feature vector is compared with each person's centroid using Euclidean distance.

The closest centroid determines the predicted identity. A distance threshold determines whether the face is labeled as known or unknown.

## Limitations

- Recognition accuracy depends on the quality and diversity of the captured images.
- Lighting, head orientation, facial expressions, and camera quality may affect results.
- The model uses PCA-based feature representations and nearest-centroid classification rather than a modern deep-learning face recognition model.
- The unknown-face threshold is estimated from training distances and is not a substitute for evaluation on independent test data.
- Performance has not been established for all users, environments, or demographic groups.

## Conclusion

EigenVision demonstrates how PCA can reduce the dimensionality of facial images and represent them using eigenfaces. By combining mathematical analysis, image preprocessing, webcam-based detection, and nearest-centroid classification, the project connects theoretical concepts from linear algebra and statistics with a practical computer vision application.
